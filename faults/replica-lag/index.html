Read replica lag: chaos experiment for Kubernetes

A read replica falls behind. A share of reads return old data, which users experience as lost changes.

What it tests
read-your-writes routing, staleness tolerance
The hypothesis holds when
Reads that must be fresh go to the primary, and the rest tolerate staleness.
It breaks when
Stale reads are served as if they were current.
