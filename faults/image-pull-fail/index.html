Registry outage: chaos experiment for Kubernetes

The container registry becomes unreachable and some pods are lost. Replacements that need to pull the image sit in ImagePullBackOff; nodes that already cache it can start without the registry.

What it tests
imagePullPolicy, image caching on nodes, replacement startup
The hypothesis holds when
IfNotPresent with the image cached on every node: replacements start without ever touching the registry.
It breaks when
imagePullPolicy Always turns a registry blip into a hard dependency on every pod restart.
