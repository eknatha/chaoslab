Vector database latency: chaos experiment

Retrieval for a RAG pipeline slows down. Each request waits on the vector store before it can reach the model.

What it tests
timeouts on retrieval, degraded answers without context
The hypothesis holds when
A short retrieval timeout falls back to an answer without context.
It breaks when
No timeout: the whole request waits for retrieval and latency moves with it.
