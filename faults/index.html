Kubernetes fault catalogue

Self-healing & HA

  • Pod kill — ReplicaSet self-healing, PodDisruptionBudgets, startup time
  • Container kill — restartPolicy, liveness probes, crash loop backoff
  • Node drain — PodDisruptionBudgets, spare capacity, rescheduling time
  • Zone outage — topology spread constraints, multi-zone capacity
  • Node NotReady — taint-based eviction, tolerationSeconds, replica headroom
  • Kubelet restart — readiness re-evaluation, replica headroom, probe thresholds

Capacity & storage

  • CPU stress — CPU limits, HPA reaction time, request latency under contention
  • Memory pressure — memory limits, OOMKilled handling, crash loop backoff
  • Disk fill — ephemeral storage limits, eviction thresholds, write paths
  • Surge + slow scale-up — HPA and KEDA reaction time, Cluster Autoscaler, priority and preemption
  • Volume detach — storage failure handling, replacement attach time, replica headroom

Network & edge

  • Network delay — client timeouts, circuit breakers, readiness probe timeouts
  • Packet loss — retry policy, TCP behaviour, probe failure thresholds
  • DNS blackhole — DNS caching, connection reuse, dependency failure handling
  • CoreDNS failure — NodeLocal DNSCache, client-side caching, connection keep-alive
  • Ingress outage — ingress controller replicas, anti-affinity, edge availability
  • Mesh latency injection — request timeouts, retries, circuit breaking
  • Mesh abort injection — retry policy, error budgets, graceful degradation

Control plane & startup

  • etcd latency — control-plane dependence: scheduling, reconciliation, HPA, endpoint updates
  • API server throttling — controller retry behaviour, API Priority and Fairness, scheduling under rejection
  • Registry outage — imagePullPolicy, image caching on nodes, replacement startup
  • ConfigMap deleted — startup dependence on configuration, safe rollout of config changes

Delivery & GitOps

  • Bad release — readiness gating, rollout strategy, automated rollback
  • GitOps drift — self-heal, drift detection, reconciliation interval
  • Bad commit synced — rollback to last good revision, difference between self-heal and rollback

AI workloads

  • GPU node loss — GPU spare capacity, slow model load, eviction timing
  • Model cold start — readiness gating, warm pools, model download time
  • LLM provider 429 storm — fallback provider, backoff, timeouts, graceful degradation
  • Vector database latency — timeouts on retrieval, degraded answers without context
  • Inference queue saturation — event-driven scaling, load shedding, queue buffering

Security & identity

  • Certificate expiry — automated renewal, expiry alerting
  • Secret rotated under running pods — hot reload of credentials, restart on change
  • Admission webhook fails closed — failurePolicy, webhook availability, blast radius of policy engines
  • Image signature check fails — supply-chain policy availability, fail-open vs fail-closed
  • NetworkPolicy blocks DNS — default-deny policies, DNS egress rules, caching
  • RBAC change breaks the autoscaler — headroom when scaling cannot help, permission change review

Data & messaging

  • Primary database failover — multi-AZ failover time, retries, read-only degradation
  • Cache loss and stampede — stale-while-error, request coalescing, timeouts
  • Broker partition loss — producer buffering, retries, replication factor
  • Read replica lag — read-your-writes routing, staleness tolerance
  • Work queue backlog — consumer scaling on lag, buffering

Cloud & regions

  • Primary region outage — active-active vs warm standby, failover time, DNS health checks
