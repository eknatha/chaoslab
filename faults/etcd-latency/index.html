etcd latency: chaos experiment for Kubernetes

Slows every write the control plane makes. Running pods are untouched, so it looks harmless until something needs the control plane. The experiment adds ordinary pod churn to find out.

What it tests
control-plane dependence: scheduling, reconciliation, HPA, endpoint updates
The hypothesis holds when
The workload carries enough headroom that slow rescheduling is invisible to requests.
It breaks when
Replacement pods start late, endpoints lag behind reality, and the autoscaler reacts several times slower.
