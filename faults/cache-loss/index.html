Cache loss and stampede: chaos experiment for Kubernetes

The cache cluster restarts empty. Every request falls through to the database at once, which slows down and rejects some of them.

What it tests
stale-while-error, request coalescing, timeouts
The hypothesis holds when
Stale entries, request coalescing and a short timeout keep the database from being overrun.
It breaks when
The stampede is the outage.
