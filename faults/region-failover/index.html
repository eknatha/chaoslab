Primary region outage: chaos experiment

The primary region becomes unreachable. What happens next is decided by how the second region was set up: serving already, or waiting to be promoted.

What it tests
active-active vs warm standby, failover time, DNS health checks
The hypothesis holds when
Both regions serve traffic and health checks move users within seconds.
It breaks when
A passive standby needs DNS to move and caches to warm, which takes longer than the objective allows.

Reference

  • Route 53 DNS failover
  • Amazon RDS Multi-AZ
