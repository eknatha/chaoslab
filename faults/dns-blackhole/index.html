DNS blackhole: chaos experiment for Kubernetes

Cuts the target pods off from cluster DNS. The most common real outage nobody rehearses: everything looks healthy until a connection needs a fresh lookup.

What it tests
DNS caching, connection reuse, dependency failure handling
The hypothesis holds when
Cached lookups and kept-alive connections carry traffic through the outage.
It breaks when
Every new connection needs a fresh lookup, so errors begin as soon as a pooled connection is recycled.
