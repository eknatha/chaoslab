Packet loss: chaos experiment for Kubernetes

Drops a percentage of packets. Retries mask small losses and amplify large ones — this is where a retry storm starts.

What it tests
retry policy, TCP behaviour, probe failure thresholds
The hypothesis holds when
Retries with backoff absorb the loss and the probes tolerate a few failures.
It breaks when
Aggressive retries amplify load, and probe failure thresholds restart pods that were only slow.
